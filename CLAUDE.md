# Portfolio repo

This repo is the permanent home for the `portfolio-allocator` skill (`.claude/skills/portfolio-allocator/`).

Cloud sessions run in throwaway containers, so files only survive if they are committed and pushed. When running the skill here:

- Read `portfolio-allocator-history.md` from the repo root (Phase 2).
- Save each run's `portfolio-allocation-YYYY-MM-DD.md` under `allocations/` and update `portfolio-allocator-history.md` in the repo root.
- Commit and push both files at the end of every run so the next run can see the history.
